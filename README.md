## 本地使用

```bash
git clone https://github.com/dannykocko/ai-nav-site.git
cd ai-nav-site
open index.html        # macOS；或直接用浏览器打开 index.html
```

也可以起一个本地静态服务器（可选）：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 部署到 GitHub Pages

1. 在 GitHub 新建一个公开仓库，例如 `ai-nav-site`。
2. 把本项目推上去：

```bash
git init
git add .
git commit -m "AI 资源导航站第一版"
git branch -M main
git remote add origin https://github.com/dannykocko/ai-nav-site.git
git push -u origin main
```

3. 打开仓库的 **Settings → Pages**，Source 选 **Deploy from a branch**，Branch 选 `main` / `/ (root)`，保存。
4. 等一两分钟，访问 `https://dannykocko.github.io/ai-nav-site/` 即可。

也可以用 Cloudflare Pages / Vercel / Netlify 直接导入这个仓库，同样零配置。

## 如何添加 / 修改资源

所有数据都在 `app.js` 的 `DATA` 数组里，往里面加一行即可：

```js
{
  n: "工具名",                 // 名称
  u: "https://example.com",    // 官网链接（必须是真实、可访问的地址）
  d: "一句话中文介绍。",        // 描述
  c: "生图",                   // 分类：免费资源 / 生图 / 生视频 / 写作对话 / 编程 / 音频音乐 / 搜索办公 / 设计 / 效率
  t: ["标签1", "标签2"],        // 标签（用于搜索）
  p: "免费",                   // 价格徽章：免费 / 免费试用 / 付费 / 开源
  v: true,                     // 是否人工核实过（只有真正核实过的才写 true）
  note: "补充说明，如额度和到期时间。"   // 可选；不填就删掉这一行
},
```

加完刷新页面即可看到；分类按钮在 `app.js` 底部的 `CATEGORIES` 里定义。
